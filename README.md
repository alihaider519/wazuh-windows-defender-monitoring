# Windows Defender Security Monitoring with Wazuh

## Overview

This project is a hands-on Windows security monitoring lab built using **Wazuh SIEM** and a Windows endpoint. The goal was to monitor and investigate Windows Defender security activity through centralized security event collection and Wazuh alerts.

## Lab Environment

- **SIEM:** Wazuh
- **Endpoint:** Windows
- **Agent Name:** `windows112`
- **Monitoring:** Windows Defender security events

## What I Monitored

The lab focused on Windows Defender activity, including:

- Windows Defender security scans
- Changes in Windows Defender protection status
- Windows security events related to Defender activity
- Wazuh alerts generated from Windows event logs

## Investigation Process

1. Configured a Windows endpoint with the Wazuh agent.
2. Connected the Windows endpoint to the Wazuh manager.
3. Monitored Windows Defender events through Wazuh.
4. Investigated Defender scan activity and protection-status events.
5. Reviewed the related Windows security logs and Wazuh alerts to understand the endpoint activity.
